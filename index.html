Mapeamento de Bem-Estar Urbano:
Automação de Zeladoria com IA

O fim das rondas manuais. Um pipeline que usa Visão Computacional (YOLOv8) para varrer as ruas, calcular a saúde da via e disparar payloads JSON direto pro SAP S/4HANA quando o limite crítico é atingido.

Python YOLOv8 REST API

O Problema e a Orquestração

Hoje, a prefeitura depende de denúncias ou vistorias presenciais pra achar um problema. É lento e custoso. A solução foi montar um pipeline 100% cloud para agir de forma preditiva.

01. Telemetria (Colab)

O script Python varre o repositório no Drive buscando capturas da rua. Pega a imagem bruta e prepara para a requisição.

02. Inferência (YOLOv8)

Bate na API do Roboflow. O modelo escaneia os pixels procurando classes específicas (`entulho`, `fios_expostos`) e devolve as coordenadas.

03. Gatilho ERP (SAP)

A lógica calcula o Health Score da via. Se bater menos de 70, estrutura um JSON e faz um POST no SAP abrindo o chamado de manutenção (M1).

Desafios e Aprendizados Técnicos

Driblando o "Small Data" e Overfitting

O maior gargalo inicial foi a base de dados. Treinar IA com poucas imagens locais originais (24 fotos) gera o risco clássico de overfitting — a rede decora as fotos em vez de aprender o padrão. A saída técnica foi aplicar Data Augmentation no pré-processamento. Inseri filtros de brilho e ruído pra simular a rua em dias nublados e fim de tarde, multiplicando a base para mais de 50 imagens sintéticas e deixando o modelo cascudo.

Lógica de Negócio vs. Detecção

Não basta a IA achar o lixo, ela tem que tomar decisão corporativa. Aprendi na prática como amarrar o resultado do modelo com uma regra de negócio. Criei o algoritmo do Health Score: o script pesa a quantidade de lixo (peso 10) e fios (peso 15). O ERP não é inundado com chamados inúteis; o payload só é disparado via POST para a Alemanha se o score da rua for realmente crítico.

O Impacto Social e Urbano

A tecnologia pela tecnologia não serve de nada se não resolver um problema real na ponta. No desenvolvimento desse projeto de extensão, ficou claro como a zeladoria afeta diretamente o cidadão em Juiz de Fora.

  • Prevenção de Acidentes Detectar fiação caída ou exposta não é estética, é segurança pública. O bot reduz o tempo de resposta das concessionárias de dias para minutos, evitando acidentes.
  • Bem-Estar e a Teoria das Janelas Quebradas Entulho acumulado destrói a acessibilidade e passa a sensação de abandono, o que atrai mais degradação e pequenos delitos. Ruas limpas e ordenadas afetam a saúde mental coletiva e devolvem a rua pro cidadão.

Da Reação para a Prevenção

O maior ganho social deste projeto é provar que a gestão pública não precisa ser puramente reativa. Com IA leve rodando no background, a cidade passa a cuidar da própria infraestrutura antes mesmo que o morador precise ligar pra reclamar.
